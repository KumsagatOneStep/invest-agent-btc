# Инвест-агент: заметки обсуждения (2026-10-20)

Черновик. Спецификация: `superpowers/specs/2026-10-20-invest-agent-design.md`. Источник — разговор с пользователем.

## Решено пользователем

- Цель — **краткосрочные сигналы** (потом, возможно, и долгосрочная часть).
- Капитал — **200 000 ₸** (~$400).
- Рынки в перспективе — все (крипта, США/ETF, KASE), но начинаем с одного.
- Схема — **гибрид**: сигналы считает код, Claude фильтрует и объясняет.
- Сигнал приходит в **Telegram**, сделку пользователь открывает **вручную**.
- Время пользователя — **утром и вечером**, днём на работе.
- Описание ниже (ритм, содержание сигнала, этапы) пользователь принял без правок («нет, продолжай»).
- Аккаунты есть: **Binance** (крипта) и **Freedom Finance** (акции), верификация пройдена.

## Принятое описание (предложено Claude, правок не было)

**Ритм.** Сигналы дважды в день — утром (~8:00) и вечером (~20:00), время настраивается. Днём агент молчит.

**Горизонт.** Свечи 4ч и дневные, сделка 1–10 дней. Вход по сигналу, сразу ставятся стоп-лосс и тейк-профит ордерами на бирже — днём следить не надо.

**Содержание сигнала:**
- монета и направление — только покупка (спот, без плеча);
- зона входа, стоп-лосс, цель — готовыми числами;
- сумма в ₸ и $ по правилу «риск не больше 1–2% счёта на сделку»;
- короткое объяснение от Claude: почему вход и что против;
- срок годности: если цена ушла от зоны входа к следующему окну — сигнал отменяется.

**Другие сообщения:**
- вечерняя сводка по открытым сделкам;
- еженедельная статистика: % прибыльных, результат после комиссий, сравнение с «просто держать BTC».

**Этапы:**
1. Бумажная торговля 2–3 месяца: сигналы приходят, журнал сам считает итог каждой сделки.
2. Реальные деньги — только если пройдены критерии: ≥100 сигналов, прибыль после комиссий, лучше «купить и держать», просадка в допустимых пределах. Сначала часть суммы (~50 000 ₸).

## Предложено Claude (ждёт подтверждения)

- Первый рынок — **крипта на споте** (BTC, ETH + несколько крупных монет): 24/7, бесплатная история, низкий порог, комиссия ~0,1%.
- Техника: Python, Claude API, Telegram-бот, запуск на сервере (не на Mac).
- 2–3 простые стратегии (тренд, возврат к среднему) с бэктестом с учётом комиссий.

## Открытые вопросы

1. ~~Биржа~~ → Binance (крипта), Freedom Finance (акции, на потом).
   Заметка Claude: на споте Binance есть OCO-ордер (стоп + тейк одной заявкой), комиссия 0,1%
   (0,075% при оплате в BNB); публичные свечи без API-ключа — для бумажного этапа ключ не нужен.
2. Сервер: пользователь спросил «какой вариант лучший». Рекомендация Claude — **принята пользователем («да давай»)**:
   отдельный маленький VPS в Европе (1–2 vCPU, 2 ГБ, ~€4–5/мес), не общий с helpdesk-ботом
   (рабочий проект с ПДн, к тому же helpdesk пока запущен только локально). Европа — потому что
   Binance не отдаёт данные с IP из США. Бесплатный вариант — GitHub Actions по расписанию,
   но там IP из США (Binance блокирует), задержки запуска и нет «живого» бота.
3. Бюджет в месяц (VPS + Claude API): **пользователь — $20–30**.
   Рекомендация Claude: держать фактический расход ~$8–12 (VPS ~$5, Claude ~$3–7: дешёвая модель
   на рутину, сильная — только на объяснение сигналов), жёсткий месячный лимит в коде.
   Честно сказано: $20–30 ≈ 5–7% капитала в месяц — на реальном этапе агенту нужно отбивать
   расходы; в статистике считать результат и до, и после расходов на сервер/API.
4. Список монет: **выбирает агент** (решение пользователя). Правило — предложение Claude:
   спот-пары к USDT, топ 8–10 по объёму торгов за 30 дней, без стейблкоинов, обёрнутых и
   плечевых токенов, только монеты с историей ≥ 1 года (нужна для бэктеста); список
   пересчитывается раз в месяц, BTC и ETH всегда в списке.
5. Допустимая просадка: пользователь спросил «как лучше». Предложение Claude — **принято пользователем («да давай»)**:
   риск 1% счёта на сделку (не 2%); от пика счёта −10% → предупреждение и риск 0,5%;
   −15% → агент перестаёт давать сигналы, разбор и возврат на бумагу; возобновление только
   решением пользователя. Те же правила на бумажном этапе; критерий перехода на деньги —
   просадка на бумаге не больше 15%.


## Разбор TradingAgents (TauricResearch, v0.7.0, Apache-2.0)

Мультиагентный конвейер на LangGraph: 4 аналитика → дебаты бык/медведь →
трейдер → риск-команда → портфельный менеджер → рейтинг Buy…Sell.

**Перенять:**
- защита от заглядывания в будущее (point-in-time данные, вход по первому закрытию после решения);
- журнал решений с автосверкой через N дней и сравнением с бенчмарком;
- дебаты «за/против» как защита от самоуверенности;
- цены берутся из проверенного снимка данных, а не из модели;
- статус REVIEW вместо молчаливого Hold, если ответ не разобран.

**Не подходит как генератор краткосрочных сигналов:**
- только дневные свечи, удержание 5 дней;
- нет комиссий и проскальзывания;
- десятки вызовов LLM на тикер — дорого и медленно;
- результат не воспроизводится;
- заточен под акции, крипта — побочный режим;
- сигнал словесный, без точных входа/выхода.
